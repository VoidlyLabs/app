# Voidly App

Minimal storefront built with Next.js, React Query, and Tailwind CSS.

## Features

- Product catalog and product details
- Category filtering
- Product purchase flow
- Sign in, registration, profile, and logout
- Storefront configuration from the backend

## Requirements

- Node.js 20+
- npm
- Running Voidly backend

## Environment

Create `.env`:

```env
NEXT_PUBLIC_BACKEND_URL=http://localhost:3000
ORIGIN=http://localhost:3000
```

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```
